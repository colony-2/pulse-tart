# macOS cell provider

Implement `github.com/colony-2/pulse-provider-api.Provider` as an importable Go library with Orchard and direct Tart backends. No provider CLI, plugin framework, YAML loading, or independent supervisor. Scope is macOS ARM64 concurrency slots; Linux guests and shared volumes are deferred.

**Configuration and ownership.** Both constructors take the same typed `Config` for bases, slot groups, state, and bootstrap. Orchard adds connectivity and worker placement; Tart adds executable/home and SSH/command timeouts. Copy mutable inputs. Default slot size is 4 vCPU / 8192 MiB; count zero drains. One runtime locks each private durable state directory. One host owns each backend/owner scope. Constructors create no VMs; the host explicitly drives reconciliation.

**Bases.** Catalog entries declare a concrete name, explicit aliases, digest-pinned OCI image, actual macOS version, SSH access, and capabilities. Use names like `macos-sequoia-15.7.7-arm64`; never label a different OS version as Tahoe. Selectors use exact equality or one trailing `*`, case-sensitively, with no inferred aliases. Capabilities use exact all-of set semantics. Verify OS version and configured built-in tool capabilities inside each template before readiness.

**Slots.** Independently clone, configure, boot and prepare one template per slot. Install pinned Nix/c2j/tools and verify an unused guest with no lease, execution intent, or worker service. Capture boot UUID and MAC; reject duplicate template MACs. Suspend only after readiness. Persist template identity, configuration fingerprint, phase and worker. Jobs clone the untouched suspended source on the same host, preserving all saved hardware. A boot UUID/MAC guard rejects cold-boot fallback before lease delivery. One unresolved/active clone reserves its slot; different slots use different MACs. No queue: warming/busy slots decline with `no_capacity`.

**Submit.** Validate complete immutable launches and distinct batch IDs before dispatch. Match a fitting base and slot; use its actual fixed resources. Reject malformed quantities, identities, selectors and empty leases. Decline unsupported runtime caps, start-before deadlines, scratch reservations and unmatched environments/capabilities before side effects. Past deadlines are rejected. Never claim replacement work.

Construct `c2j run with-lease --jobdb … --job-id … --lease-file - --ci --input-mode fail`. Pass the exact opaque lease through stdin, never argv/environment/logs/listings. Pass actual CPU, memory, platform, pinned image/digest and verified capability facts using the pinned c2j's supported flags. Preserve resolved base as `PULSE_BASE`; no nonexistent `--execution-base` flag. The lease authorizes c2j to retrieve secrets; the provider receives no job secrets. Preserve LaunchID and full JobRef in durable/native metadata and listings.

**Admission and recovery.** Fsync a keyed request/native fingerprint and slot reservation before native creation. Identical launch IDs return their existing outcome; conflicting assignments are rejected. Accepted means the Orchard create response or local detached Tart dispatch succeeded; boot/delivery/execution may still fail. Lost responses remain `unknown`, including after absence in inventory. Never retry ambiguous clone/run operations. Observed matching native identity may resolve uncertainty. Keep terminal history for the owner scope's lifetime. Version 3 journals reject legacy state rather than resetting it.

**Backend execution.** Orchard uses REST startup scripts, events and power-state updates; labels select workers and must not carry arbitrary correlation fields. Direct Tart uses literal CLI arguments, preserves suspended-clone hardware, checks active MAC collisions, and detaches `tart run --no-graphics --suspendable`. Bind direct ownership to a private UID marker, directory identity and hardware. SSH delivers scripts through stdin. Persist private delivery data so host restart can retry idempotent delivery without repeating native launch. Closing the library never kills native jobs.

**Guest lifetime.** Root launchd owns bootstrap/delivery independent of the SSH session. Execute c2j once as the unprivileged worker account after durably recording intent. Bound setup and missing-delivery time, never the runtime of a zero-timeout worker. Shut down after c2j exits. Environment preparation is reusable only in unused image builders; never sanitize an executed VM for another job.

**Reconciliation and listing.** `Run`/`Reconcile` manage lifecycle. `List` is read-only, paginated, scoped, and excludes templates/terminal work. Preserve JobRef and LaunchID; expose no lease. Observation failure is an error, not an empty successful inventory. `Slots` exposes operational state only. Configuration changes and `Drain` retire idle templates while preserving unresolved jobs. Missing known unused templates may be rebuilt; ambiguous creates remain reserved; failed builds are retained for inspection.

**Cleanup.** Never infer worker absence from age, failed status alone, or unreachable SSH. Require a native stopped observation. Recheck exact name, UID and immutable specification before deletion; quarantine mismatches. Direct Tart additionally validates local directory ownership. Finish when the owned native API/local record is absent; no additional physical-removal proof is required. Never prune by prefix or delete unrelated VMs.

**Security and testing.** Private state directories, atomic fsynced journals, sanitized errors, no redirects, verified controller TLS and explicit insecure lab HTTP. Lease-bearing native delivery records remain private. Optional direct SSH host-key pinning; otherwise trust the managed guest endpoint. Deterministic tests cover API validation, resource/base resolution, c2j invocation, duplicates, unknown dispatches, concurrent reservations, recovery, read-only listing, template identity, cleanup and HTTP/SSH process boundaries. Live tests cover two-slot preparation/resume, host-library reopen, reuse, and real JobDB execution through the public Submit API. A disposable fixture validates Nix execution, lease-bound secret retrieval, renewal beyond the initial lifetime, completion, and completed/expired lease rejection without reacquisition. The full-suite script fails on skipped/missing live assertions and saves redacted, Git-ignored reports before cleanup. Direct Tart live tests run on macOS.
